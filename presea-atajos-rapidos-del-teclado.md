# 💡 Presea: Atajos rápidos del teclado

| Atajo       | Para qué sirve                                                                                                           | Desde dónde                          |
| ----------- | ------------------------------------------------------------------------------------------------------------------------ | ------------------------------------ |
| `F7`        | [Alta rápida de cliente](presea-atajos-rapidos-del-teclado.md#alta-rapida-de-cliente-f7)                                 | Ticket / Factura, campo CLIENTE      |
| `CTRL + L`  | [Buscar cliente por CUIT o DNI](presea-atajos-rapidos-del-teclado.md#buscar-cliente-por-cuit-o-dni-ctrl--l)              | Campo "Desde cliente"                |
| `F8` x2     | [Desimputar un comprobante](presea-atajos-rapidos-del-teclado.md#desimputar-un-comprobante-f8-dos-veces)                 | Historia del cliente                 |
| `CTRL + D`  | [Volcar un presupuesto al ticket](presea-atajos-rapidos-del-teclado.md#volcar-un-presupuesto-al-ticket-ctrl--d)          | Ticket                               |
| `ALT + V`   | [Ver el comprobante como reporte](presea-atajos-rapidos-del-teclado.md#ver-el-comprobante-como-reporte-alt--v)           | Historia del cliente                 |

| `CTRL + F2` | [Consulta rápida de cuenta corriente](presea-atajos-rapidos-del-teclado.md#consulta-rapida-de-cuenta-corriente-ctrl--f2) | Cualquier pantalla                   |
| `F11`       | [Consulta de stock](presea-atajos-rapidos-del-teclado.md#consulta-de-stock-f11)                                          | Cualquier pantalla                   |
| `CTRL + F8` | [Generar una nota de crédito](presea-atajos-rapidos-del-teclado.md#generar-una-nota-de-credito-ctrl--f8)                 | Ticket, antes de ingresar el cliente |
| `CTRL + F5` | [Pago con lapos Payway integrado](presea-atajos-rapidos-del-teclado.md#pago-con-lapos-payway-integrado-ctrl--f5)         | Ticket, en la parte de pagos         |
| `CTRL + O`  | [Consultar percepciones e impuestos](presea-atajos-rapidos-del-teclado.md#consultar-percepciones-e-impuestos-ctrl--o)    | Ticket, antes de pasar a pago        |
| `CTRL + Q`  | [Cerrar Presea](presea-atajos-rapidos-del-teclado.md#cerrar-presea-ctrl--q)                                              | Cualquier pantalla                   |

***

### Alta rápida de cliente — `F7`

Desde el Ticket o la Factura se pueden dar de alta los datos mínimos del cliente, sin salir de la pantalla.

Con el cursor en el campo **CLIENTE**: `F7` → vista **CONS\_FINAL** → ícono _Código disponible_ → cargar los datos.

### Buscar cliente por CUIT o DNI — `CTRL + L`

Buscar por nombre es impreciso y lento. Cuando aparece el campo **"Desde cliente"** —en la cuenta corriente o en la historia del cliente—:

`F6` → **`CTRL + L`** → seleccionar **"CUIT"** con Enter.

### Desimputar un comprobante — `F8` dos veces

Algunas operaciones no se dejan anular ni revertir porque **"El comprobante se encuentra imputado"**. Para liberarlo:

Desde la historia del cliente, pararse sobre el comprobante → `F8` → `F8` otra vez sobre el mismo comprobante para que pida la contraseña → ingresar el código → Enter.

<div align="left"><figure><img src=".gitbook/assets/image (299).png" alt="" width="563"><figcaption></figcaption></figure></div>

<div align="left"><figure><img src=".gitbook/assets/image (300).png" alt="" width="270"><figcaption></figcaption></figure></div>

> ⚠️ **El código de desimputación lo da Administración.** No se comparte por los grupos de sucursales.

### Volcar un presupuesto al ticket — `CTRL + D`

Si el presupuesto ya está hecho, volcarlo al ticket respeta el descuento —siempre que el cliente no cambie el método de pago— y el precio del producto, mientras siga vigente dentro del plazo estipulado.

En el Ticket: **`CTRL + D`** → N° del presupuesto, o `F6` para buscarlo por cliente.

### Consulta rápida de cuenta corriente — `CTRL + F2`

**`CTRL + F2`** → buscar el nombre del cliente **en MAYÚSCULAS** y pararse sobre el que corresponde → **`F8`** para ver el detalle.

### Generar una nota de crédito — `CTRL + F8`

Desde el Ticket, **antes de ingresar el cliente**: **`CTRL + F8`**.

<div align="left"><figure><img src=".gitbook/assets/image (311).png" alt="" width="563"><figcaption></figcaption></figure></div>

> ⚠️ **Cuál corresponde en cada caso:**
>
> * **Nota de Crédito** → cuando es parcial.
> * **Reversión de Ticket/Factura** → cuando es por el total, o cuando hay que devolver por Mercado Pago.
> * **Conversión de Ticket/Factura** → cuando se pasa de un cliente a otro.

***

### Pago con lapos Payway integrado — `CTRL + F5`

Se carga el ticket como de costumbre y, al llegar a la parte de pagos, **`CTRL + F5`**.

<div align="left"><figure><img src=".gitbook/assets/image (312).png" alt="" width="563"><figcaption></figcaption></figure></div>

> 📝 **"Payway (sin prom. por tarjeta)", código 4002**, se usa únicamente con **CUENTA DNI** → "BILLETERA MEDIANTE QR", y solo los **miércoles y jueves**, según el cuadro de promociones vigente.

***

### Consultar percepciones e impuestos — `CTRL + O`

Para verificar que las percepciones e impuestos estén bien aplicados al cliente: **`CTRL + O`**, antes de pasar a la parte de pago.

<div align="left"><figure><img src=".gitbook/assets/image (313).png" alt="" width="563"><figcaption></figcaption></figure></div>

***

### Cerrar Presea — `CTRL + Q`

Para cerrar rápido una de las tantas ventanas de Presea que quedan abiertas.
