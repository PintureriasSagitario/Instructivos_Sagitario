# Anulación NDV

Cuando el proceso arranca desde una nota de venta la forma de anularla es desde: 

- **Nota de Crédito x nro de factura:** Este ítem se usa cuando hicimos la factura pero **NO** se despacho (**Sin Remito**).
- **Devolución:** Este ítem se usa cuando se hizo una factura desde una nota de venta y **SI** se despacho **Tiene Remito, es cuando devuelve productos**

⚠️ Si la nota de venta no se facturo ni se despacho hay que eliminarla desde [**Bajas](Bajas%20344b06ef7592809fbf0be32157b707e8.md).** Si se anulan algunos productos nada mas hay que [**Modificar**](Modificaci%C3%B3n%20NDV%20343b06ef759280fab9b8eee018b4b5d5.md) la NDV
