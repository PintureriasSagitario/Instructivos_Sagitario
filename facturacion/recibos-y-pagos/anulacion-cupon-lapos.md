# Anulación Cupón - Lapos Integrado

Si tenemos que anular un cupón que se hizo con el Lapos integrado tenemos que hacerlo desde el sistema.

1. Vamos a ir desde Ventas - Integración con Lapos - Anular operación de venta / Devolucion sobre operación de venta.

📌Anular operacion de venta: Se usa cuando el cobro se efectuó este mismo día y todavia no se cerro el lote.

📌 Devolucion sobre operación de venta: Se usa cuando la venta es de otro día y esta el cierre de lote realizado.

<figure><img src="../../.gitbook/assets/image (36) (1).png" alt=""><figcaption></figcaption></figure>

{% hint style="warning" %}
&#x20;Para hacer la devolucion necesitamos tener el cupón físico y la tarjeta del cliente.
{% endhint %}

2. Nos abre esta ventana en donde vamos a poner la fecha que figura en el cupón, el numero de lote, numero de cupón.<br>

<div><figure><img src="../../.gitbook/assets/image (43) (1).png" alt=""><figcaption></figcaption></figure> <figure><img src="../../.gitbook/assets/image (42) (1).png" alt=""><figcaption></figcaption></figure></div>

<figure><img src="../../.gitbook/assets/image (44) (1).png" alt=""><figcaption></figcaption></figure>

3. Y confirmamos si esa es la venta a la cual queremos hacerle la anulación. Le damos aceptar y nos aparece una imagen para que veamos el posnet físico.

<div><figure><img src="../../.gitbook/assets/image (45) (1).png" alt=""><figcaption></figcaption></figure> <figure><img src="../../.gitbook/assets/image (46) (1).png" alt=""><figcaption></figcaption></figure></div>

4. Aca hacemos los mismos pasos que para la venta, seleccionamos la anulación.

<div><figure><img src="../../.gitbook/assets/image (48).png" alt=""><figcaption></figcaption></figure> <figure><img src="../../.gitbook/assets/image (49).png" alt=""><figcaption></figcaption></figure> <figure><img src="../../.gitbook/assets/image (50).png" alt=""><figcaption></figcaption></figure></div>

5. Y en el sistema nos aparece arriba a la derecha la leyenda de anulación exitosa y sale el cupon con la anulación.

✅ Y listo, ya queda la anulación hecha.

{% hint style="info" %}
A tener en cuenta que una vez que nosotros hacemos la anulación de pago puede no ser inmediata la acreditación en la cuenta del cliente. Esto va a depender del banco y si es crédito o débito.
{% endhint %}
