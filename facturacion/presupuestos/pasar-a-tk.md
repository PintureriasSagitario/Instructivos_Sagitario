# Pasar Presupuesto a TK

Para pasar el presupuesto a un TK se hace desde Ventas - Comprobantes - Tickets

![Captura de pantalla 2026-03-30 160811.png](../../imagenes/Captura_de_pantalla_2026-03-30_160811.png)

- Lo primero que tenemos que hacer es en el numero de cliente apretar CNTRL + D
    
    ![image.png](../../imagenes/image%2065.png)
    

👉🏽 Si tenemos el numero del presupuesto se ingresa ahi y sino con F6 lo buscamos por numero de cliente, en el caso de no saber el numero de cliente apretamos F6 de nuevo y lo buscamos por nombre.

![image.png](../../imagenes/image%2066.png)

- Una vez seleccionado el cliente, con ENTER nos va a traer todos los presupuestos de ese cliente. Con ENTER seleccionamos el que vamos a usar.
    
    ![image.png](../../imagenes/image%2067.png)
    
- Nos abre esta ventana y solo nos va a dejar modificar la columna de DESPACHO. Ahi tenemos que poner la cantidad de productos de cada uno que el cliente se va a llevar. En el caso de que el cliente no se quiera llevar algun producto ese item lo dejamos en 0.

![image.png](../../imagenes/image%2068.png)

- Con ESCAPE nos pregunta si queremos finalizar el ingreso de Productos y si volcamos el presupuesto. En ambas le damos ACEPTAR.

![image.png](../../imagenes/image%2063.png)

![image.png](../../imagenes/image%2069.png)

- Nos va a abrir la ventana de Tickets, desde ahi podemos agregar mas productos, borrarlos o dejarlo como esta.

![image.png](../../imagenes/image%2070.png)

✅ Una vez que los productos estén Ok. Con escape vamos a valores y ponemos el medio
de pago con el que el cliente abone y listo!
