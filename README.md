# 📚 Instructivos Sucursales

Bienvenida al manual de procedimientos del sistema **Presea**. Acá vas a encontrar todos los instructivos organizados por sección para que puedas consultar cualquier proceso paso a paso.

---

## 👉 Secciones

### 👥 Clientes
Todo lo relacionado con el alta, consulta y gestión de clientes en el sistema.

### 🧾 Facturación
Presupuestos, tickets, recibos, notas de venta, cierre de caja y más.

### 📦 Stock
Recepción de pedidos de fábrica, control de stock y recepción entre locales.

### ⚠️ Errores Presea
Solución de errores frecuentes del sistema.
