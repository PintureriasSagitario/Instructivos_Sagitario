# 2️⃣ Control de Cheques

Controlá que todos los cheques hayan sido ingresados correctamente.

---

## Consultar el listado

**Ruta:** `Finanzas → Consultas → Listados de cheques y valores`

Nos trae un listado con todos los datos. Controlá: **banco, vencimiento y número de cheque**.

---

## Modificar un dato incorrecto

**Ruta:** `Finanzas → Tablas → Modificación cheques en cartera`

Se abre una ventana donde podés modificar:
- Banco
- Número de cheque
- Vencimiento
- Si es Endosable

Una vez modificado, volvé a tirar el listado para verificar que quedó OK. ✅
