# Historia de Cliente

Para ver todos los comprobantes y todo el historial del cliente en todas las sucursales vamos a ir desde Ventas - Clientes -  Historia de Cliente. 

![image.png](../imagenes/image%2010.png)

- Se abre un cuadrito y vamos a buscar solamente por cliente con el codigo o con F6 lo buscamos por nombre. Si no lo encontramos le podemos preguntar al cliente el numero de dni o cuit y con Control + L lo buscamos por Cuit y aceptamos.

![image.png](../imagenes/image%2011.png)

✅ Y listo! Nos va a abrir todos los comprobantes que se le hicieron a ese cliente.
